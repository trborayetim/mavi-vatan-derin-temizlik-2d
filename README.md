# Mavi Vatan: Derin Temizlik

GameUP Türkiye Programı Oyun Hackathonu kapsamında COP31 hedefleri doğrultusunda geliştirilen 2D Eko-Arcade keşif ve lojistik simülasyonu.

## 🎮 Canlı Demo
[Oyunu Tarayıcıda Oynamak İçin Tıklayın](https://trborayetim.github.io/mavi-vatan-derin-temizlik-2d/)

## 📖 Oyunun Amacı (Odak: Okyanuslar ve Sıfır Atık)
Zifiri karanlık Akdeniz çukurlarında bağımsız projektör feneri olan bir denizaltıyı yöneterek plastik ve toksik atıkları tespit ediyoruz. Amacımız; sınırlı batarya ve 50 KG atık tankı kapasitesiyle deniz ekosistemine zarar vermeden atıkları toplamak ve derinliği sürekli değişen mobil "Geri Dönüşüm İstasyonu"na ulaştırarak toplam 250 KG atığı dönüştürmektir.

## ⌨️ Kontroller (Bağımsız Çift Kontrol Sistemi)
* **W, A, S, D:** Denizaltıyı hareket ettirir.
* **Yön Tuşları (← ↑ → ↓):** Feneri (projektörü) araçtan bağımsız olarak 360° çevirir.

## 🛠️ Teknik Altyapı
* HTML5 Canvas API
* Vanilla JavaScript (Dış kütüphane veya oyun motoru kullanılmamıştır)
* CSS3 Glassmorphism UI
